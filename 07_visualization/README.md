# 07 — Visualization

## Purpose

This stage documents the visualization procedures used to summarize and interpret transcriptomic results generated during the project.

Visualizations were designed to provide an interpretable representation of sample structure, gene-expression patterns, differential-expression results, and targeted chemokine–receptor signals.

---
