# Data

This directory contains the curated metadata required to
interpret the biological samples included in the analysis.

The original GEO expression data are not redistributed in
this repository. They can be accessed through GEO accession
**GSE185055**.

The analysis used 24 biological samples representing four
colorectal cancer cell lines under 2D and 3D culture conditions.

Cell lines:
- HCT116
- HT29
- LS174T
- LS513

Each cell-line × condition group contained three biological
replicates.
